# MINSKA Android 0.5

Ny testfunktion: automatisk butiksdetektering utan AI.

- GPS-position används för att söka efter butiker inom cirka 1,2 km.
- OpenStreetMap/Overpass används för supermarket, convenience, kiosk och mall.
- Upp till 40 butiker registreras som Android-geofences i 24 timmar.
- När du senare går in i en butikszon kan MINSKA visa en notis om minst ett dagsmål redan är nått.
- Internet krävs när butikszonerna hämtas.
- För bakgrundsvarningar behöver Android tillåta plats i bakgrunden.
- AI är fortfarande inte ansluten.

Obs: OpenStreetMap-data kan sakna vissa butiker eller ha felaktiga uppgifter.
